# ZMK Helper Android

Android端末から、GitHub Actionsで生成されたZMKキーボードのファームウェアを取得して更新するアプリです。

Download firmware generated by GitHub Actions and update a ZMK keyboard directly from an Android device.

[日本語](#日本語) | [English](#english) | [Releases](https://github.com/te9no/ZMKHelperAndroid/releases)

## 日本語

### 主な機能

- GitHub OAuth Device Flowによるログイン
- public/private repositoryのGitHub Actions成果物取得
- ブランチ、ビルド、artifact、artifact内ファームウェアの選択
- API結果とダウンロード済みartifactのキャッシュ
- USB mass storage bootloaderへのUF2書き込み
- BLE OTA DFU ZIPの転送と再試行
- UF2から[`zmk-feature-blueboot`](https://github.com/te9no/zmk-feature-blueboot)用OTA ZIPへの変換
- USB CDCログ表示と1200 baud bootloader trigger
- USB/BLE書き込み進捗表示

### 必要なもの

- Android 8.0（API 26）以降
- GitHubへ接続できるインターネット環境
- USB更新: USB host/OTG対応端末、データ通信対応ケーブルまたはOTGアダプター
- BLE OTA: Bluetooth LE対応端末と、BLE DFU対応ファームウェア
- 対象キーボードに正しく対応したファームウェア

> [!WARNING]
> 別のボード、左右、shield、bootloader向けのファームウェアを書き込むと、キーボードが起動しなくなる場合があります。artifact名とファイル名を確認し、バッテリー残量を確保してから更新してください。

### クイックスタート

1. [最新の署名済みAPK](https://github.com/te9no/ZMKHelperAndroid/releases/latest)をインストールします。
2. `Menu`または画面左端からのスワイプでメニューを開き、`Login with GitHub`を選びます。
3. repository URLまたは`owner/repo`を入力し、`Save repo`を押します。
4. `Select Branch`でブランチを選び、`Load successful Actions builds`を押します。
5. `Select Artifact`、続けて`Select Firmware`で対象ファイルを選びます。
6. `USB UF2`または`BLE OTA`を選び、表示された主ボタンから更新を開始します。

初回操作、権限、USB/BLE/CDCの詳しい手順、エラー対処は[日本語ユーザーガイド](docs/guide-ja.md)を参照してください。

## English

### Features

- Sign in with GitHub OAuth Device Flow
- Access GitHub Actions artifacts from public and private repositories
- Select a branch, workflow run, artifact, and firmware file
- Cache API results and downloaded artifacts
- Copy UF2 firmware to a USB mass-storage bootloader
- Transfer and retry BLE OTA DFU ZIP packages
- Convert UF2 into an OTA ZIP for [`zmk-feature-blueboot`](https://github.com/te9no/zmk-feature-blueboot)
- View USB CDC logs and invoke a 1200-baud bootloader trigger
- Show USB and BLE update progress

### Requirements

- Android 8.0 (API 26) or later
- Internet access to GitHub
- USB updates: a USB host/OTG-capable Android device and data-capable cable or OTG adapter
- BLE OTA: Bluetooth LE and firmware with a compatible BLE DFU bootloader
- Firmware built for the exact target keyboard

> [!WARNING]
> Flashing firmware for a different board, side, shield, or bootloader can leave the keyboard unable to boot. Verify the artifact and file names and ensure sufficient battery power before updating.

### Quick start

1. Install the [latest signed APK](https://github.com/te9no/ZMKHelperAndroid/releases/latest).
2. Open the side menu with `Menu` or a swipe from the left edge, then choose `Login with GitHub`.
3. Enter a repository URL or `owner/repo`, then tap `Save repo`.
4. Choose a branch with `Select Branch`, then tap `Load successful Actions builds`.
5. Choose the target with `Select Artifact`, followed by `Select Firmware`.
6. Select `USB UF2` or `BLE OTA`, then use the primary action shown for that transport.

See the [English user guide](docs/guide-en.md) for first-time setup, permissions, detailed USB/BLE/CDC procedures, and troubleshooting.

## Privacy and credentials

The GitHub access token is stored in the app's private preferences and is used only for GitHub API and artifact requests. Android backup is disabled. Use `Clear GitHub token` before transferring or disposing of the device.

GitHub tokenはAndroid端末内のアプリ専用領域に保存され、GitHub APIとartifact取得にのみ使用されます。Androidバックアップは無効です。端末を譲渡・廃棄する前に`Clear GitHub token`を実行してください。
